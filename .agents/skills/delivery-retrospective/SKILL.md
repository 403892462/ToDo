# 交付复盘

仅在 Gate 3 人工批准后生成最终复盘。使用受控复盘入口消费已校验来源，同时输出机器可读摘要和中文 Markdown。

## 边界

- Gate 3 未批准时停止，不生成当前周期最终复盘。
- 事实必须链接周期、运行、验证、独立审计、交付及有效指标来源。
- 将事实、推断、数据缺口和建议分开；未知成本、token 或耗时保持未知并说明原因。
- 建议初始状态为 `PENDING`，不得直接修改需求、方案、计划、实现或 Gate。
- 接受建议必须引用新的 `CHG-*` 受控变更或后续周期；拒绝和延期只更新建议记录。
- 不覆盖既有复盘版本，不把无效指标纳入事实汇总。
