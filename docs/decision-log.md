## DEC-001 首版移动端技术形态

- 状态：APPROVED
- 问题：首版应实现为可安装的移动端 Web/PWA，还是原生/跨平台移动应用？
- 决定：采用 Next.js、TypeScript、Tailwind CSS、shadcn/ui、@dnd-kit/core 和 Vercel AI SDK；首版按手机端响应式 Web 应用实现，不额外扩展未批准的拖拽业务行为。
- 决策人：dezhi
- 决策时间：2026-11-04
- 影响：决定项目结构、运行方式、可安装能力和唯一验证命令。

## DEC-002 第三方大模型接入方式

- 状态：APPROVED
- 问题：使用哪家模型 API，以及密钥由后端代理保管还是直接放在客户端？
- 决定：采用可配置的 OpenAI 兼容 API，由 Next.js 服务端路由作为最小代理保管密钥；前端不接触密钥，自动测试使用模拟响应。
- 决策人：dezhi
- 决策时间：2026-11-04
- 影响：决定网络边界、配置方式、开发启动命令和 AI 解析工作项。
