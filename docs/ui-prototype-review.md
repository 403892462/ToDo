## v1.3 匿名空间与公网持久化增量预览

- 适用基线：Requirements Baseline v1.3。
- 首次使用：未授权浏览器先显示“创建个人空间”和“使用访问码恢复”两个入口；创建成功后只展示一次空间 ID 与访问码，并要求用户确认已保存后进入任务首页。
- 恢复空间：用户输入访问码；验证期间显示处理中状态；成功后进入同一任务空间，失败时使用统一提示，不暴露空间是否存在。
- 正常任务页：沿用 v1.2 今日视图、批量自然语言创建、编辑、完成、删除及筛选交互；数据来源改为当前 PostgreSQL 个人空间。
- 空状态：新空间无任务时沿用今日视图空状态，并明确这是新的个人空间，不导入浏览器中的 v1.2 旧任务。
- 保存成功：创建或编辑成功后刷新当前空间任务，并显示简短成功反馈。
- 数据库异常：保留已确认旧数据，不显示虚假成功；就地提示“保存失败，请稍后重试”，允许用户再次提交。
- 管理员验证：独立管理入口依次收集用户名、强密码和动态验证码；失败时统一提示，成功后才显示按空间 ID 恢复的功能。
- 不可逆重置：管理员提交空间 ID 后显示二次确认，明确“新访问码生成后旧码立即失效”；成功时新码只展示一次并记录审计结果。
- 恢复审计：管理员可查看按时间倒序排列的恢复记录；不展示访问码、密码、动态验证码秘密或数据库凭据。
- 手机与 HTTPS：上述普通用户核心流程采用单栏手机布局；正式环境通过 HTTPS 域名访问。

## v1.2 批量创建增量预览

- 适用基线：Requirements Baseline v1.2。
- 核心流程：用户在底部闪念输入框提交一段包含多项任务的文本；提交期间输入框禁用并显示“正在解析…”。
- 创建成功：任务按原文顺序分别进入今日时间轴或任务池；底部反馈“已创建 N 条任务”。
- 部分未识别：可识别任务正常创建，失败片段以原文任务创建；底部警示“已创建 N 条任务，部分任务未识别”。
- 超过上限：按原文顺序创建前 10 条；底部警示“已创建前 10 条任务，其余任务未创建”。
- 整体 AI 失败：沿用 v1.1 降级状态，只以整段原文创建一条任务并提示“AI 解析失败”。
- 空状态、编辑任务、永久删除确认：不受 CHG-006 影响，沿用已批准的 v1.1 界面与交互。
- 反馈约束：结果提示不得遮挡底部输入框，并提供关闭入口；新的下一次提交开始时清除上一条结果提示。

## 待确认改进

### UI-001 清理过期状态提示

- 优先级：高
- 证据：步骤 5 仍显示步骤 3 的“AI 解析失败”，即使用户已完成编辑和筛选。
- 建议：用户开始下一操作或任务创建结果被处理后，自动清除旧状态；成功与失败提示使用可关闭或限时状态。

### UI-002 本地化优先级显示

- 优先级：中
- 证据：步骤 5 显示内部值“优先级：high”，而编辑表单使用“高”。
- 建议：列表统一显示“高／中／低”，内部仍保留 `high/medium/low`。

### UI-003 修复模态框焦点管理

- 优先级：高
- 证据：打开 AI 提示、编辑和删除确认时，DOM 快照显示焦点仍停留在背景按钮或复选框。
- 建议：打开时聚焦对话框首个合理控件，背景设为不可交互，支持 Escape 关闭并在关闭后恢复触发控件焦点。

### UI-004 增强空状态引导

- 优先级：低
- 证据：步骤 1 下半屏大面积留白，只有一句说明。
- 建议：增加 2～3 条不涉及新功能的自然语言示例，帮助首次用户理解输入格式。
