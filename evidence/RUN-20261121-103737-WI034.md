## 实施结果

- 指标按事件保存为独立 JSON，使用排他创建防止覆盖或并发写入同一事件。
- 校验规范 ISO 8601 时间、非负毫秒、成功/失败/重试次数及结果一致性。
- 质量指标仅接受测试、构建、契约检查和独立审计类型，并要求真实状态与来源引用。
- 调用量和 token 只记录提供方真实返回值；字段未知时保存 `null` 和缺失原因。
- 成本已知时要求金额、币种、提供方和来源；未知时不估算，并记录原因。
- 无效指标写入独立数据质量问题，不创建指标事件，也不修改运行、验证或审计证据。
- 敏感字段被拒绝，CLI 错误摘要执行脱敏和长度限制。
- 新增 `project-metrics collect/validate` 受控入口及中文指标事件模板。
